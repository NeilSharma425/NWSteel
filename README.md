# NW Steel Website

A modern, clean, and professional website for NW Steel - a leading steel fabrication and manufacturing company in the Northwest region.

## Features

- **Modern Design**: Clean, minimal design with professional aesthetics
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Smooth Animations**: Engaging scroll animations and transitions
- **Interactive Navigation**: Sticky navigation with active link highlighting
- **Contact Form**: Fully validated contact form with user feedback
- **Performance Optimized**: Fast loading times and smooth scrolling
- **Accessibility**: Keyboard navigation support and proper ARIA labels

## Sections

1. **Hero Section**: Eye-catching hero with call-to-action buttons
2. **About Section**: Company overview with statistics
3. **Services Section**: Detailed service offerings with icons
4. **Projects Section**: Showcase of completed projects
5. **Contact Section**: Contact information and inquiry form
6. **Footer**: Company links and additional information

## Technologies Used

- **HTML5**: Semantic markup for better SEO
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for interactions and animations
- **Google Fonts**: Inter and Poppins font families

## Color Scheme

- Primary: Dark blues (#1a1a2e, #16213e, #0f3460)

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - pure HTML/CSS/JS

## Customization

To customize the website for your needs:

1. **Content**: Edit the HTML in `index.html`
2. **Styling**: Modify CSS variables in `styles.css` (lines 13-36)
3. **Colors**: Update the color scheme in CSS variables
4. **Images**: Replace the SVG placeholders with actual images

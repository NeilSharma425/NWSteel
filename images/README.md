# Images Directory Structure

This folder contains all images for the Northwest Steel & Pipe website.

## Folder Organization

### `/warehouse/`
Photos of the warehouse facility, storage areas, and operations
- warehouse-exterior.jpg
- warehouse-interior.jpg
- facility-aerial.jpg

### `/equipment/`
Photos of processing equipment and machinery
- plasma-cutter.jpg
- saw-machine.jpg
- shear-machine.jpg
- ironworker.jpg
- delivery-truck.jpg

### `/products/`
Photos of steel products and inventory
- steel-beams.jpg
- steel-plate.jpg
- steel-pipe.jpg
- steel-angles.jpg
- steel-inventory.jpg

### `/logos/`
Company logos and branding
- nwsteel-logo.png (main logo for navbar)
- nwsteel-logo-white.png (white version for dark backgrounds)

## Image Guidelines

**Recommended Dimensions:**
- **Hero images**: 1920x1080px or larger
- **Product photos**: 800x600px minimum
- **Equipment photos**: 1200x800px
- **Logos**: PNG format with transparent background, 500px width

**File Formats:**
- Use **JPG** for photos
- Use **PNG** for logos and graphics with transparency
- Optimize all images before uploading (compress to reduce file size)

## How to Add Images

1. Download images from the old website gallery
2. Place them in the appropriate folder above
3. Name them according to the naming convention shown
4. Images will automatically appear on the website pages

## Image Usage

Images are used across these pages:
- **index.html**: Hero images, warehouse photos, product previews
- **about.html**: Company history photos, facility images
- **services.html**: Equipment photos, processing machinery
- **inventory.html**: Product photos, steel inventory
- **contact.html**: Facility location image

All images are responsive and will scale appropriately on mobile devices.
